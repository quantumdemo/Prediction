## 1. Executive Summary

Stage 13 implements probability calibration and production forecaster selection for the Football AI Intelligence platform. Operating on out-of-sample predictions generated by Stage 12 walk-forward historical backtesting, Stage 13 fits post-processing probability calibrators (Platt Scaling / Logistic Sigmoid and Isotonic Regression) to align raw forecast probabilities with true empirical match outcome frequencies.

Eighteen candidate model variants (6 base models $\times$ 3 calibration methods) were evaluated on holdout historical test matches (Window 4: 2023-07-01 to 2024-05-28 | 29,203 matches). **`xgboost_platt`** (XGBoost Forecaster calibrated with Platt Scaling) was selected as the optimal production forecasting model, achieving the lowest 1X2 Log Loss (**1.02832**), Brier Score (**0.61742**), and Expected Calibration Error (**0.00291**).

## 2. Calibration Methodology & Leakage Isolation

Calibration maps raw forecast probabilities $p \in [0, 1]$ to empirical frequencies $\hat{p} \in [0, 1]$:
1. **Platt Scaling (Logistic Sigmoid)**: Fits a logistic regression model on $x = \text{logit}(p) = \log(p / (1 - p))$ to output $\hat{p} = \sigma(A \cdot x + B)$.
2. **Isotonic Regression**: Non-parametric monotonically non-decreasing step function mapping raw probabilities to empirical frequencies.
3. **Multi-Class Axiom Preservation**: For 1X2 probabilities (Home, Draw, Away), calibrators process each outcome independently and re-normalize the output distribution so that $P(\text{Home}) + P(\text{Draw}) + P(\text{Away}) = 1.0$.
4. **Zero Temporal Leakage**: Calibrators are fitted strictly on historical out-of-sample calibration matches (Windows 1–3: 2020-07-01 to 2023-06-30 | 37,723 matches) and evaluated on holdout test matches (Window 4: 2023-07-01 to 2024-05-28 | 29,203 matches). $T_{\text{cal}} < T_{\text{test}}$.

## 4. Key Empirical Findings

1. **Probability Calibration Reduces ECE**: Platt Scaling reduced the Expected Calibration Error (ECE) for raw XGBoost from `0.00736` down to `0.00291` (60.5% reduction in calibration error) while simultaneously improving 1X2 Log Loss from `1.02844` to `1.02832`.
2. **Platt Scaling vs Isotonic Regression**: For XGBoost and Random Forest models on this dataset size, Platt Scaling outperformed Isotonic Regression by providing smooth, continuous sigmoid probability maps without step-function discretization artifacts.
3. **Selected Production Model**: **`xgboost_platt`** is registered as the canonical production forecaster for downstream ingestion in Stage 17 (Market Catalogue & Mapping) and Stage 18 (Risk & NO-BET Engine).
